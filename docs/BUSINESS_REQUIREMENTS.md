# GML - 대표님 확인 필요 사항: Business & Functional Requirements

## Context

이 문서는 GML(Global Mission Light) 플랫폼을 개발하면서, **개발자 입장에서 대표님과 반드시 논의해야 할 비즈니스 요구사항과 기능 요구사항**을 정리한 것입니다.

특히 **미국 텍사스 소재 501(c)(3) 법인이 한국 교회에 기부금을 전달**하는 크로스보더 구조이므로, 양국의 법률/세무/규제를 고려한 요구사항이 포함되어 있습니다.

기존 시스템 설계 원본은 `docs/ORIGINAL_PLAN.md`를 참고하세요.

## Part 1: 비즈니스 요구사항 (대표님 확인 필수)

### 1.1 법인/세무 관련 확인 사항

#### ✅ 501(c)(3) 면세 단체 등록 상태
- [ ] **EIN (Employer Identification Number)** 확보 완료 여부
- [ ] **501(c)(3) Determination Letter** 발급 완료 여부
- [ ] **텍사스주 법인 등록** 상태 (Good Standing 유지 여부)
- [ ] **연방 Form 990** 보고 의무 준수 여부 (면세 단체는 매년 재무 보고 필수)

> ⚠️ **Action Required**: 영수증에 EIN과 501(c)(3) 승인 날짜를 명시해야 하므로, 이 정보를 개발팀에 공유 필요

#### ✅ 한국 내 법인/세무 등록
- [ ] 한국 내 사무소 또는 대표자 등록 여부
- [ ] 한국 외국환거래법상 **비영리법인 해외송금 요건** 충족 여부
- [ ] 한국 국세청 **고유번호증** 발급 여부 (필요시)

> 📌 **참고**: 2026년 1월부터 무증빙 해외송금 한도가 연간 10만 달러로 통합 운영됩니다. [출처](https://www.korea.kr/news/policyNewsView.do?newsId=148956081)

### 1.2 크로스보더 기부금 송금 구조

#### ✅ 기부금 흐름 확인

**현재 가정된 구조:**
```
멘티(미국/한국) → Stripe → GML 법인(텍사스) → 한국 교회
```

**확인 필요 사항:**
1. [ ] **GML 법인의 은행 계좌** 위치 (미국 은행 또는 한국 은행?)
2. [ ] **한국 교회로의 송금 방법**:
   - 직접 은행 송금 (Wire Transfer)
   - 한국 내 대리인을 통한 전달
   - 기타 방법
3. [ ] **송금 주기**: 매월? 분기별? 일정 금액 누적 시?
4. [ ] **환율 처리**: USD → KRW 환전 시점 및 방법
5. [ ] **송금 수수료 부담**: 기부금에서 차감? 별도 운영비?

> ⚠️ **리스크**: 한국 외환거래법상 비영리법인의 해외송금은 증빙 서류(사업 계획서, 정관, 재무제표 등)가 필요할 수 있습니다. 은행과 사전 협의 필요.

### 1.3 기부금 인정 여부 (Quid Pro Quo 이슈)

#### ✅ IRS Quid Pro Quo 규정

**핵심 이슈:**
> 멘티가 멘토링 서비스를 받는 대가로 결제하는 구조에서, 이것이 순수 "기부"로 인정될 수 있는가?

**IRS 규정 요약:**
- **Quid Pro Quo Contribution**: 기부자가 기부 대신 goods/services를 받는 경우
- **$75 초과 시**: 반드시 goods/services의 공정시장가치(Fair Market Value, FMV)를 명시해야 함
- **예시**: 기부자가 $100을 내고 $40 가치의 콘서트 티켓을 받으면, 실제 기부금은 $60입니다.

[출처: IRS - Quid Pro Quo Contributions](https://www.irs.gov/charities-non-profits/charitable-organizations/charitable-contributions-quid-pro-quo-contributions)

**GML 플랫폼의 경우:**
- 멘토는 **무보수 재능기부** (자원봉사)
- 멘티가 받는 멘토링 서비스의 FMV를 어떻게 산정할 것인가?
  - Option 1: 멘토링은 멘토의 재능기부이므로 FMV = $0 (순수 기부)
  - Option 2: 유사 시장 멘토링 가격을 FMV로 산정 (부분 기부)

**확인 필요 사항:**
- [ ] **법률/세무 전문가 자문**: 이 구조가 순수 기부로 인정될 수 있는지 확인
- [ ] **영수증 문구**: "No goods or services were provided" vs "Services valued at $X were provided"

> ⚠️ **Critical Decision**: 이 결정에 따라 영수증 생성 로직이 달라지므로, 개발 전 반드시 확정 필요

### 1.4 개인정보보호 (미국 CCPA + 한국 PIPA)

#### ✅ 미국 개인정보보호법 (CCPA)
캘리포니아 거주 사용자가 있을 경우 CCPA 준수 필요:
- [ ] 개인정보 수집/사용 목적 명시
- [ ] 사용자 데이터 삭제 요청 처리 프로세스
- [ ] 제3자(Stripe, Resend 등) 데이터 공유 고지

#### ✅ 한국 개인정보보호법 (PIPA)
한국 거주 사용자 데이터 처리 시:
- [ ] **개인정보 처리방침** 작성 (한국어)
- [ ] **해외 이전 동의**: Supabase(미국 서버), Stripe(미국) 데이터 저장 시 명시적 동의
- [ ] **개인정보보호책임자** 지정 및 연락처 공개

**확인 필요 사항:**
- [ ] 서버 위치 선택: Supabase 리전 (미국 vs 아시아)
- [ ] 데이터 보관 기간 정책
- [ ] 개인정보 파기 절차

### 1.5 이용약관/법적 고지 필요 사항

#### ✅ Terms of Service (이용약관)
- [ ] **멘토 이용약관**: 재능기부 조건, 책임 범위, 세션 취소 정책
- [ ] **멘티 이용약관**: 결제/환불 정책, 기부금 전환 동의, 세금 공제 한계 명시
- [ ] **준거법**: 미국 텍사스주법 or 한국법?
- [ ] **분쟁 해결**: 중재 조항, 관할 법원

#### ✅ Privacy Policy (개인정보 처리방침)
- [ ] 한국어 버전 필수
- [ ] 쿠키 사용 고지 (GDPR-style 배너 필요 여부)

#### ✅ Disclaimer (면책 조항)
- [ ] 멘토링 결과에 대한 책임 범위
- [ ] 기부금 사용처 변경 가능성 명시
- [ ] 세금 공제 최종 책임은 기부자에게 있음 명시

### 1.6 운영 정책 결정 사항

#### ✅ 멘토 승인 프로세스
- [ ] **승인 기준**: LinkedIn 인증, 경력 검증, 추천서 등
- [ ] **승인 담당자**: 누가 심사하고 승인하는가?
- [ ] **승인 소요 시간**: 목표 처리 기간 (예: 3영업일)
- [ ] **거절 시 피드백**: 거절 사유 통보 여부

#### ✅ 세션 가격 정책
- [ ] **가격 범위**: 최소/최대 금액 제한 (예: $30~$500)
- [ ] **가격 책정**: 멘토가 자유롭게 설정? 플랫폼 권장 가격?
- [ ] **가격 변경**: 멘토가 언제든 변경 가능? 승인 필요?

#### ✅ 환불 정책
- [ ] **환불 가능 조건**: 세션 취소 시점, 멘토 불참 등
- [ ] **환불 방법**: Stripe 환불 → 기부금 기록 취소
- [ ] **영수증 처리**: 환불 시 영수증 무효화 방법

#### ✅ 기부처 선정 및 공개
- [ ] **기부처 선정 기준**: 어떤 교회/단체를 지원하는가?
- [ ] **기부처 공개 범위**: 전체 공개 vs 일부만 공개
- [ ] **기부금 배분 방식**: 균등 배분 vs 필요 기반 배분

## Part 2: 기능 요구사항 (구현 전 확인 필요)

### 2.1 멘토 관리 정책

#### ✅ 멘토 프로필 필수 정보
- [ ] **필수 항목**: 이름, 회사, 직무, 자기소개, LinkedIn, 세션 가격
- [ ] **선택 항목**: 위치, 전문분야(다중 선택 가능?), 사진
- [ ] **프로필 사진 요구사항**: 최소 해상도, 파일 크기 제한

#### ✅ 캘린더 연동 방식
- [ ] **외부 링크만 제공**: Calendly, Cal.com 등 URL 입력
- [ ] **향후 확장**: 플랫폼 내 예약 시스템 구축 계획 여부

#### ✅ 멘토 비활성화/탈퇴
- [ ] **비활성화**: 일시적으로 세션 중단 (프로필 숨김)
- [ ] **탈퇴**: 계정 완전 삭제 vs 익명화 처리
- [ ] **과거 기부 기록**: 탈퇴 후에도 보존 필요

---

### 2.2 결제/기부 플로우 상세

#### ✅ Stripe Checkout 흐름
1. 멘티가 "세션 예약 + 기부하기" 클릭
2. 서버에서 Checkout Session 생성 (세션 가격 + 수수료 계산)
3. 멘티가 Stripe Hosted 페이지에서 결제
4. 결제 완료 → Webhook → 서버가 donations 테이블에 기록

**확인 필요 사항:**
- [ ] **수수료 투명성**: 멘티에게 "세션 가격 $100 + 수수료 $3.20 = 총 $103.20" 표시 방식
- [ ] **영수증 자동 발송**: 결제 즉시 vs 기부금 전달 완료 후?
- [ ] **테스트 환경**: Stripe Test Mode로 충분히 테스트 후 Production 전환

#### ✅ 수수료 계산 로직
```
세션 가격: $100 (USD)
Stripe 수수료: 2.9% + $0.30 = $3.20
멘티 총 결제: $103.20
기부 전달액: $100.00 (전액)
```

**확인 필요 사항:**
- [ ] **Non-profit 할인**: Stripe의 501(c)(3) 할인(1.99% + $0.30) 신청 완료 여부?
  - 신청 시 수수료가 약 30% 절감됨
- [ ] **국제 카드 수수료**: 해외 카드 사용 시 추가 1% 수수료 처리 방법

### 2.3 영수증/세금 관련 기능

#### ✅ 기부 영수증 필수 포함 정보
```
- 영수증 번호: GML-2026-00001 (자동 증가)
- 단체명: Global Mission Light
- EIN: [실제 EIN 번호]
- 501(c)(3) 승인 날짜: [실제 날짜]
- 기부자명: [멘티 이름]
- 기부자 이메일: [멘티 이메일]
- 기부 날짜: [결제 완료 날짜]
- 기부 금액: $100.00 USD
- 501(c)(3) 면책 문구:
  "Global Mission Light is a 501(c)(3) tax-exempt organization.
   Your donation is tax-deductible to the extent allowed by law.
   [Quid Pro Quo 문구 - 법률 검토 후 확정]"
```

**Quid Pro Quo 문구 옵션:**
- **Option A (순수 기부)**: "No goods or services were provided in exchange for this contribution."
- **Option B (부분 기부)**: "The estimated fair market value of services received is $X. Your tax-deductible amount is $Y."

#### ✅ 영수증 생성 및 발송
- [ ] **PDF 생성 라이브러리**: jsPDF or Puppeteer (HTML to PDF)
- [ ] **저장 위치**: Supabase Storage `/receipts/2026/GML-2026-00001.pdf`
- [ ] **이메일 발송**: Resend를 통해 자동 발송 (결제 후 5분 이내)
- [ ] **재발송 요청**: 멘티가 대시보드에서 영수증 재다운로드 가능
