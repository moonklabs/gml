## 리스크 및 대응 방안

### 기술적 리스크

| 리스크 | 영향도 | 대응 방안 |
|--------|--------|---------|
| Supabase RLS 정책 오류 | 높음 | 철저한 테스트, 관리자 승인 프로세스 |
| Stripe Webhook 실패 | 높음 | 재시도 로직, 수동 확인 프로세스 |
| 이메일 발송 실패 | 중간 | 재발송 기능, 대시보드에서 재다운로드 |
| 성능 저하 (DB 쿼리) | 중간 | 인덱스 최적화, 캐싱 전략 |

### 비즈니스 리스크

| 리스크 | 영향도 | 대응 방안 |
|--------|--------|---------|
| 멘토 승인 프로세스 지연 | 중간 | 자동화된 알림, 간단한 승인 대시보드 |
| 세금 공제 법률 문제 | 높음 | 법률 전문가 자문, 명확한 disclaimer |
| 초기 멘토 부족 | 높음 | 직접 리크루팅, 인센티브 프로그램 |
