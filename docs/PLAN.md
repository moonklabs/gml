### 🎯 현재 작업: 프론트엔드 UI 리뷰용 목 데이터 기반 앱 구현

**목표**: Supabase 환경변수 없이도 빌드/실행 가능하도록 전환하여, 대표님이 전체 화면 UI를 빠르게 리뷰할 수 있는 환경 구축

**전략**:
- 목 데이터를 Supabase 쿼리 결과 형식과 동일하게 구조화하여, 나중에 Supabase 복구 시 UI 코드 최소 변경
- 기존 페이지 UI는 100% 보존하며 데이터 소스만 교체
- 미구현 페이지(임팩트, 대시보드, About, FAQ)를 목 데이터 기반으로 우선 완성
- 총 17개 파일 작업 (수정 7개, 신규 10개)

**목 데이터 기반으로 Supabase 없이 독립 실행 가능:**

```bash
npm install
npm run build    # 빌드 성공 확인
npm run dev      # 개발 서버 실행
```

**확인 가능한 페이지 (9개):**
- `/` - 랜딩 (히어로 + 서비스소개 + 임팩트 + 멘토 미리보기 + FAQ)
- `/mentors` - 멘토 목록 (검색/필터 + 카드 6개)
- `/mentors/mentor-1` - 멘토 상세 (프로필 + 전문분야 + 세션)
- `/impact` - 임팩트 (카운터 애니메이션 + 기부처 + 리포트)
- `/about` - 소개
- `/faq` - FAQ
- `/auth/login` - 로그인 UI
- `/auth/signup` - 회원가입 UI
- `/dashboard/profile` - 멘토 대시보드 (프로필 편집 폼)
